# Window Agent

Window Agent 是 Windows 側欄助理，可依你已授權的 Chrome 分頁內容回答問題。

1. [下載 Windows 安裝包](./WindowAgent-0.4.3-Windows-Store.zip)，解壓縮後執行 Install-WindowAgent.exe。
2. 瀏覽 [Chrome 線上應用程式商店頁面](https://chromewebstore.google.com/detail/nohlpaceehkkfjlaigfkfpnkieemajha)，商店核准發佈後即可加入 Chrome。
3. 依安裝包內的手冊設定自己的模型端點與 API 金鑰，再選擇要授權的網站。
